# VHDL Multiplexer on ZedBoard

This project demonstrates the implementation and synthesis of different VHDL multiplexer architectures on a Xilinx ZedBoard FPGA using Vivado.

## Overview
The project analyzes several VHDL modeling styles for a multiplexer and compares their RTL and synthesized netlists.

## Features
- RTL Analysis
- VHDL multiplexer implementations
- FPGA synthesis
- Synthesized schematic analysis
- ZedBoard support

## Architectures
- arch1 : when-else structure
- arch2 : case statement
- arch3 : nested if statements
- arch4 : elsif structure

## Hardware
- Xilinx ZedBoard
- XC7Z020 FPGA

## Tools
- Vivado
- VHDL
